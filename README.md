# GDGoC_Python_Study
GDGoC 8기 파이썬 스터디 기록용 레포지토리입니다.

## 스터디 방법
- 매 주 자신의 트랙에 해당하는 스터디 자료를 학습한다.
- 멘토가 제공한 관련 문제를 풀어본다.
- 깃허브에 업로드 후 피드백을 받는다.

**스터디 자료**
```
https://opal1031.tistory.com/category/GDGoC/Python
```

## 레포지토리 관리
- 매 주 개인 branch 생성 후, 과제를 제출하면 됩니다.
- 멘토가 과제 확인 후에 피드백 메시지와 함께 main에 Merge합니다.

#### 커밋 메시지 작성법
```shell
feat: prob01
```

#### main branch와 동기화 명령어
```shell
git pull origin main
```
